# Detekcia nástrojov pre PHP

| Čo | Ako | Výsledok |
|---|---|---|
| príkazy Doctrine | `nettrine/*` → `orm:validate-schema`, `migrations:*`; inak `doctrine:*`, ak ich registrácia (`grep -rn 'schema:validate\|validate-schema' app bin config`) alebo `AGENTS.md`/`CLAUDE.md` projektu potvrdí; nezistené → „nezistené“ v pláne (opraví ho odpoveď na otázku 1) | `{{schemaValidateCmd}}`, `{{migrationsCmd}}` |
| audit | Zisti presný príkaz, jeho runtime, skutočnú cestu k lockfile a schválený zdroj. Pri neštandardnej ceste uprav aj `requires` podľa projektu. Predpoklady spoločného vstupu zachovaj pre celý harness. | `{{composerAuditCommand}}` |
| PHPStan | zober celý príkaz z aktívnych pravidiel, harnessu alebo CI. Over jeho volanie z koreňa vrátane runtime, `--level`, `-c` a cieľov. Pri spoločnom vstupe pre PHPStan a audit pripoj jeden povinný krok. | `{{phpstanCommand}}`, `{{phpstanConfig}}`, `{{phpstanLevel}}` |
| PHPStan pri Stop | Projekt povoľuje zúženú kontrolu, príkaz prijíma `{files}` a vypisuje cestu aj riadok. Zachovaj runtime, level a config. Ak projekt povoľuje iba celý rozsah, krok vynechaj. | voliteľný `phpstan-stop` výhradne v `stop` |
| Testovacie sady | Prečítaj príkazy harnessu, CI a Composer skriptov. Over wrapper aj s argumentmi a predpokladmi jeho skutočného runtime. Jediný projektový vstup pre viac sád pripoj raz. Pri samostatnom runneri zachovaj názvy sád, skupiny, adresáre, nastavenia PHP a prepínače Testera. | `{{unitCommand}}`, `{{testerCommand}}`, `{{integrationCommand}}`, `{{migrationTestCommand}}` ako úplné príkazy spustiteľné z koreňa na hostiteľovi |
| PHPUnit | `phpunit.xml*` → `<testsuite name="…">` (presné mená vrátane veľkosti písmen) | kroky `unit` / `integration`; krok `migration` (len `full`) len so sadou testov migrácií (`<testsuite name="migration">`), inak ho vypusť bez otázky |
| Nette Tester | Pri priamom použití v overenom runtime napríklad `php vendor/bin/tester tests -s -C`. Pri kombinácii s PHPUnit zachovaj projektové adresáre `.phpt` a samostatné pomalé sady. | `{{testerCommand}}`, prípadne `{{integrationCommand}}` |
| phpcs | ruleset `phpcs.xml`, `.phpcs.xml`, `*.dist` → príkaz bez `--standard` aj bez `--ignore` (vylúčenia rieši ruleset); bez rulesetu → `--standard=PSR12 --ignore=…` zo šablóny; migrácie bez namespace mimo `db/migrations` a `migrations` → doplň ich adresár do `--ignore` | lint príkaz |
| frontend (php-nette, php-symfony) | `package.json`: `eslint`, `stylelint` v `dependencies`/`devDependencies`; config `eslint.config.*`, `.eslintrc*` alebo kľúč `eslintConfig`, resp. `stylelint.config.*`, `.stylelintrc*` alebo kľúč `stylelint`; `node_modules/.bin/<nástroj>` na hostiteľovi | kroky `eslint` / `stylelint` (`runtime: host`) a ich prípony v `commitGate.ext`; bez nástroja alebo configu krok aj prípony vynechaj bez otázky; chýba len `node_modules` → krok ponechaj, pobeží po inštalácii závislostí (spustí ju používateľ) |
